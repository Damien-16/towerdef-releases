# Bastion d'Éther — Téléchargement & Mises à jour

Dépôt public de distribution pour **Bastion d'Éther** (exécutable Windows autonome et paquets de mise à jour automatique).

## Téléchargement rapide (Windows)

👉 **[Télécharger BastionDEther.exe (v1.0.0 · 6800deb)](https://github.com/Damien-16/towerdef-releases/raw/main/release/BastionDEther.exe)**

- **Aucun prérequis** : pas besoin d'installer Node.js ni de configurer quoi que ce soit.
- **Mises à jour automatiques** : à chaque lancement, le launcher vérifie automatiquement `release/version.json` sur ce dépôt et télécharge les nouvelles versions (`release/game.zip`).
- **Solo & Co-op LAN (2–4 joueurs)** : serveur HTTP/WebSocket intégré pour jouer ensemble sur le même Wi-Fi / réseau local.

> 💡 *Si Windows SmartScreen affiche un avertissement (exécutable indépendant non signé), cliquez sur **Informations complémentaires** puis **Exécuter quand même**.*
